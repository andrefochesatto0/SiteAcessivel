# Acesso no Dia a Dia

Site estático educativo sobre acessibilidade cotidiana, feito com HTML5, CSS3 e JavaScript puro. Não requer servidor, dependências ou processo de build.

## Estrutura

- `index.html`: apresentação e princípios de acessibilidade.
- `acessibilidade-visual.html`, `acessibilidade-auditiva.html`, `acessibilidade-mobilidade.html`, `acessibilidade-intelectual.html` e `tecnologia-assistiva.html`: conteúdos temáticos.
- `css/style.css`: identidade visual responsiva e modo de alto contraste.
- `js/acessibilidade.js`: controles de tamanho de fonte e contraste.

## Recursos de acesso

O site inclui navegação por teclado, foco visível, link para pular ao conteúdo, landmarks e títulos semânticos, links sublinhados, texto redimensionável, alto contraste com preferência persistente e layout responsivo. O conteúdo não depende de imagens para transmitir informação.
