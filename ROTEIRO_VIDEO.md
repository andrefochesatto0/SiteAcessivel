# Roteiro para apresentação em vídeo

1. Apresente o projeto **Acesso no Dia a Dia** e seu objetivo educativo.
2. Explique a estrutura: página inicial, cinco páginas temáticas, CSS compartilhado e JavaScript sem bibliotecas.
3. Demonstre o menu e o link “Pular para o conteúdo principal” usando Tab e Enter.
4. Mostre os controles A−, A e A+ e o botão de alto contraste. Explique que as preferências ficam salvas no navegador.
5. Apresente rapidamente os temas visual, auditivo, mobilidade, cognitivo e tecnologia assistiva.
6. Mostre o layout em uma tela estreita e comente o uso de HTML semântico, foco visível e links descritivos.
7. Encerre lembrando que acessibilidade é uma prática contínua e deve incluir testes com pessoas e tecnologias assistivas.
